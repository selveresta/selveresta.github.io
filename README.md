# selveresta.github.io

The developer website for Evergreen Studio, served at the root of
`selveresta.github.io`.

It exists for one requirement in particular: `app-ads.txt` is only honoured at
the root of the domain listed on the store listing, so it cannot live inside the
`eternal-arkanoid-privacy` project site. That repository still serves the
privacy policy at `/eternal-arkanoid-privacy/`; this one owns the root.

`app-ads.txt` authorises Google AdMob to sell inventory in Eternal Arkanoid.
The publisher ID in it is public by design - the whole point of the file is that
any buyer can fetch and read it.
